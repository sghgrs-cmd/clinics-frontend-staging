## 🚀 Пошаговая инструкция по деплою

### Шаг 1: Создай репозиторий на GitHub
1. Зайди на свой GitHub.
2. Создай новый репозиторий (например, `clinics-frontend-staging`).
3. **ВАЖНО:** Оставь его абсолютно пустым. Не добавляй `README`, `.gitignore` или лицензию. 

### Шаг 2: Запушь файлы с компьютера
Открой терминал, перейди в подготовленную папку и выполни эти команды (замени ссылку на свою):

```bash
cd C:\Users\Gagik\Desktop\w\cold\поиск\deploy_ready

# Инициализируем git
git init
git branch -M main

# Добавляем все 62 папки и заглушку
git add .
git commit -m "Initial deploy: 62 premium clinic mockups"

# Привязываем к твоему гитхабу (ВСТАВЬ СВОЮ ССЫЛКУ!)
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/clinics-frontend-staging.git

# Отправляем в космос
git push -u origin main
```

### Шаг 3: Настрой GitHub Pages
1. В твоём репозитории на GitHub зайди в **Settings** -> **Pages** (в левом меню).
2. Под заголовком "Build and deployment":
   - Source: выбери **Deploy from a branch**.
   - Branch: выбери **main** и папку **/(root)**.
   - Нажми **Save**.
3. Прокрути чуть ниже до раздела **Custom domain**:
   - Впиши туда свой домен: `hs-frontend.online`.
   - Нажми **Save**.
   - GitHub начнёт проверку DNS (так как ты уже настроил CNAME в Namecheap, всё должно загореться зелёным).
   - Поставь галочку **Enforce HTTPS**, как только сертификат сгенерируется (обычно занимает 5-10 минут).
